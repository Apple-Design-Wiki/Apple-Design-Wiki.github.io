# iPad Pro,2015

仅仅通过放大尺寸来拓展产品线似乎缺乏说服力，但首次可选键盘和笔，iPad 终于向生产工具迈出第一步。

![alt text](./hero_large_2x.jpg) 

## 键盘

![alt text](./compatible_large_2x.png) 

### 键盘作为保护套

需要时只需展开智能键盘即可。不需要时，将其折叠起来，即可成为 iPad Pro 的轻薄保护套。

![alt text](./easy_type_large_2x.jpg) 
![alt text](./easy_cover_large_2x.jpg)  
![alt text](./easy_watch_large_2x.jpg) 
![alt text](./keyboard_left_large_2x.jpg) 

### 按键

它的顶层由一张高度耐用的定制编织面料制成，该面料经过激光烧蚀以形成每个按键的形状。该面料还为每个按键提供弹簧般的张力，无需使用传统机制。因此，智能键盘厚度仅为 4 毫米，同时提供您期望的准确性、稳定性和令人满意的按键手感。

![alt text](keyboard_large_2x.png)

64 个无缝按键。与传统键盘不同，按键之间没有缝隙。而且它采用防水防污涂层，因此智能键盘可以防污防溅。

![alt text](image.png)

![alt text](./smartkey_large_2x.png) 

不过键盘的手感非常糟糕，按下时很硬，弹起时弹性不足，反馈软绵

### 材质

为了制造出像智能键盘一样轻薄耐用的设备，我们不能依赖传统的电线或组件。通过在薄如纸的尼龙片上蚀刻金属，我们创造了一种独特的导电材料，可实现电力和数据的双向流动。因此，您无需为智能键盘充电。将它连接到 iPad Pro 即可开始打字。同样重要的是，导电材料足够耐用，可以承受一生的折叠和展开。

![alt text](./powerful_large_2x.jpg) 

Smart Keyboard 的盖板由三种材质组成。与 Smart Cover 一样，顶层由耐用的聚氨酯制成，底层是柔软的超细纤维衬里，可在 Smart Keyboard 折叠时保护屏幕并保持屏幕清洁。中间层是 Smart Keyboard 真正先进的部分。它由一种新型导电织物材料制成，可确保 iPad Pro 和 Smart Keyboard 之间的无缝通信。

![alt text](image-1.png)
![alt text](./smart_connector_large_2x.png) 

### 接口

Smart Connector 是 Apple 设计的全新接口，可实现 Smart Keyboard 和 iPad Pro 之间的无缝通信。您可以在 Smart Keyboard 的连接边缘以及 iPad Pro 的侧面找到它。Smart Connector 与 Smart Keyboard 内部的导电织物协同工作，实现双向电源和数据交换。

## 笔

![alt text](./ipad-pro-pencil-witb-pdp-201510.png) 

### 低延迟

延迟（从您开始绘画到图像出现在屏幕上之间的微小延迟）已降低到几乎不可察觉的水平。

iPad Pro 知道您是在用手指还是 Apple Pencil。当 iPad Pro 感应到 Apple Pencil 时，子系统会以惊人的每秒 240 次的速度扫描其信号，从而获得通常用手指收集的数据点的两倍。这些数据与 Apple 设计的软件相结合，意味着您脑海中的图像与您在显示屏上看到的图像之间只有几毫秒的差别。

![alt text](./ipad-pro-pencil-pdp-201510.png) 
![alt text](./pencil_large_2x.jpg)

### 充电

取下 Apple Pencil 的磁性笔帽，露出一个 Lightning 接口，只需将其插入 iPad Pro 即可为 Apple Pencil 充电。该接口采用略微加长的设计，因此即使 iPad Pro 装在硅胶保护壳内，也可以充电。

需要注意的是，iPad Pro 实际上随附了一个公转母线条，你可以先将该线一头插入iPad Pro尾部，一头再接上Apple Pencil。作为临时方案，如果你不担心笔被折断，可以将笔直接插入 iPad Pro 尾部。

![alt text](./charge_large_2x.jpg)
